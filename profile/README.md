## Welcome To Ocean Giant Games

### Mantra 🎮️
Mantra is our proprietary 3D game engine we are currently developing. It's still in the early stages of development, but we should have something to show off soon!

### Mantra.UI 🏞️
We thought the available tools to make graphical user interfaces were a bit lacking and few of them were written natively in C#. Thanks to the folks over at Ahwoo for making their
[BRUTAL Framework](https://github.com/ahwootech/BRUTAL) public, we were able to leverage BRUTAL to help us create Mantra.UI.

### Will Mantra.UI be made public?
Yes! Our plan from the start was to make a simple and easy-to-use GUI API that anyone could use! Like our game engine, Mantra.UI is still quite early but it's already looking great! 🕶️
Check back soon!
